ReWavier

Assistenza ReWavier

ReWavier è un'app per annotare un brano o una registrazione sul momento esatto — musica, lezione o lavoro. I file restano sul tuo iPhone o iPad.

Per aiuto, un problema o una domanda sulla privacy, scrivi allo sviluppatore dalla pagina di ReWavier sull'App Store, oppure visita l'informativa sulla privacy.

Uso rapido: carica un file audio dalla libreria, tocca la traccia, poi il pulsante + per un appunto.
